# 숨은여행

여행 갈 나라를 고르면 한 화면에서 공휴일·축제, 환율, 예상 경비, 잘 알려지지 않은 명소, 주변 숙소·식당, 지도와 날씨를 보여 주고,
원하는 여행 스타일을 적으면 추천 리스트와 일정표를 만들어 주는 웹사이트입니다.
API 키가 필요한 서비스는 쓰지 않고, 백엔드 없이 프론트엔드만으로 동작합니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 처음 화면 | 3D 지구본(cobe). 나라를 누르면 스프링으로 돌아가며 정보 카드가 튀어나옴. '예산으로 찾기'로 갈 수 있는 나라를 지구본에 표시 |
| 홈 | 지금 가면 이득 지수(환율 30일 평균 대비·날씨·공휴일), 현지 생존 카드(이미지 저장), 골든아워, 짐 체크리스트, 인기 여행지 비교 |
| 일정 | 틴더식 카드 스와이프로 '가고 싶다/별로' → 스타일 기반 일정표에 반영 |
| 명소 | 숨은/유명 명소, 사진, 자세히·번역, 주변 숙소·식당, 지도, 내 위치 주변 |
| 돈 | 예상 경비(항공권·보험·통신·쇼핑 포함), 환율 계산기(커피 몇 잔), 더치페이 정산 |
| 정보 | 날씨(일출·일몰), 공휴일·축제 달력, 대표 음식·여행 팁 |
| 추억 | 인스타 스토리 크기(1080×1920) 여행 회고 카드 |

## 움직임 원칙

- 스프링 물리: 버튼은 누르면 납작해지고(스쿼시) 놓으면 살짝 튕겨 돌아옴 (CSS linear() 스프링 곡선), 탭·시트·카드는 Motion 스프링
- 숫자 롤링: NumberFlow (경비 총액·환율·지수·정산)
- 직접 만지는 곳에만 효과 (버튼·카드·시트·지구본), 나머지는 조용히
- '동작 줄이기'(prefers-reduced-motion) 설정이면 모든 효과를 끔, 휴대폰은 누를 때 짧은 진동

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다.

## 스크립트

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 + 배포용 빌드 (`dist/`) |
| `npm run build:countries` | Wikidata에서 국가 목록을 받아 `src/data/countries.json` 재생성 |
| `npm run build:cities` | Wikidata에서 나라별 주요 도시를 받아 `src/data/cities.wikidata.json` 재생성 |
| `npm run build:facts` | Wikidata에서 나라별 콘센트·전압·운전 방향·국가 번호·긴급 전화를 받아 `src/data/country-facts.json` 재생성 |
| `npm run build:foods` | Wikidata에서 나라별 대표 음식(사진 포함)을 받아 `src/data/foods.json` 재생성 |
| `npm run build:festivals` | Wikidata에서 나라별 축제를 받아 `src/data/wikidata-festivals.json` 재생성 (몇 분 걸림) |

## 직접 고칠 수 있는 데이터

| 파일 | 내용 |
|---|---|
| `src/data/festivals.json` | 주요 축제 보충 (Wikidata에 없거나 부족한 나라) |
| `src/data/costs.json` | 나라별 하루 경비 [알뜰, 보통, 고급] (31개국 + 지역 평균, USD) |
| `src/data/cities.json` | 31개국 여행 도시 좌표와 물가 보정값(factor) |
| `src/data/tips.json` | 31개국 여행 팁(팁 문화·수돗물·결제·교통·주의할 점)과 기본 현지어 표현 |
| `src/data/regions.json` | 비용 지역 평균에 쓰는 나라별 지역 분류 |
| `src/data/holidays.json` | Nager.Date가 지원하지 않는 나라(태국·대만·말레이시아·인도·UAE)의 고정 공휴일 |

## 경비 계산에 들어가는 것

- 현지 경비: 숙소·식비·교통·관광 (costs.json × 도시 물가 보정)
- 그 밖의 비용(켜고 끌 수 있음): 항공권 왕복(인천에서의 거리·성수기·예산 스타일로 추정, 직접 입력 가능), 여행자 보험, eSIM·유심, 쇼핑
- 항공권 가격을 주는 키 없는 무료 API가 없어 대표 노선 운임에 맞춘 거리 비례식으로 추정한다 (`src/lib/extras.ts`)

## 맞춤 일정은 어떻게 만들어지나

키 없이 쓸 수 있는 AI(LLM) API가 없어서 규칙 기반으로 만든다 (`src/lib/planner.ts`).

1. 자유롭게 쓴 글·선택 버튼을 키워드 사전으로 해석 (자연·사진·역사·맛집·카페·야경·숨은 곳·느긋하게 등)
2. 명소마다 취향·숨은 정도·거리로 점수를 매기고, 같은 종류가 몰리지 않게 고름
3. 중심에서의 방향으로 묶어 날짜에 나누고, 하루 안에서는 가까운 순서로 동선을 짬
4. 비 예보 날은 실내 명소로 바꾸고, 공휴일·그 지역 축제를 표시, 점심·저녁은 가까운 식당으로 채움

## 데이터 출처 (모두 키 불필요)

- 국가 정보: Wikidata (REST Countries v3.1은 폐기, v5는 API 키 필요 → REST Countries가 주던 수도·통화·인구·면적·대륙·도메인을 Wikidata로 대신 생성)
- 대표 음식·명소 사진: Wikidata·위키미디어 공용(Commons)
- 국기: flagcdn.com
- 공휴일: Nager.Date
- 환율: Frankfurter, 백업 open.er-api.com
- 축제: Wikidata SPARQL (나라별 실시간 조회가 40초 이상 걸려 미리 받아 둔 파일 사용)
- 명소·숙소·식당: Overpass API(OpenStreetMap, 늦으면 공개 미러에 같이 요청)
  - Overpass가 2.5초 안에 답하지 않으면 대체 경로를 같이 시작: 명소는 Wikidata 위치 검색, 숙소·식당은 Nominatim
  - Overpass가 완전히 실패하면 15분 동안은 대체 경로만 사용 (일부 네트워크에서 Overpass가 응답하지 않음)
  - `?diag=1`로 열면 서버별 연결 진단 화면, Wikipedia 요약, Wikimedia Pageviews
- 지역 검색: Nominatim (OSM 서버 요청은 1초에 1번 이하로 줄 세움)
- 지도: Leaflet + OpenStreetMap 타일
- 날씨·시차: Open-Meteo
- 번역: MyMemory (하루 무료 한도가 있어 버튼을 누를 때만 번역, 30일 저장. 한도 초과 시 파파고·구글 번역 링크)
- 명소 자세히: Wikidata (설명·사진·문화재 지정·세운 해·높이·홈페이지)
